# Archived results

`shortlist_top100_2026-10-15.csv` is the capacity + energy top 100 as of the 15 October 2026
checkpoint (commit 2e3a5f4), before DETA, DEA and MPA were calibrated on measured CO2 data.
It is kept so the change in ranking can be shown (`src/viz/site_data.py`, website section
"What changed"). It is a historical snapshot: do not regenerate it.
